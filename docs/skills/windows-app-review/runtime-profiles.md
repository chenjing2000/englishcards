# 按运行形态选择设计与验证

同一个应用可以同时适用多个形态。项目契约决定所需依赖、验证命令和交付方式。

| 运行形态 | 需明确的契约 | 代表性验证 |
|---|---|---|
| WPF 桌面 EXE | 窗口生命周期、运行时、交付物、用户数据与程序的位置关系 | 按影响检查绑定和命令状态、UI 线程、焦点、订阅释放与缩放。涉及托盘、登录启动、DPI 或设备时选相应实机入口。 |
| WPF + WebView2 | Windows 主机与网页的状态和权限边界、桥接消息、运行时和资源来源 | 检查无效消息、权限边界和会话切换。验证依赖和真实 WebView2。 |
| 本地浏览器服务 | 监听地址和端口、浏览器与自动化运行时、草稿来源、配置和导出位置 | 使用隔离服务和浏览器配置做 E2E，检查生产模式、下载及实际导出。 |
| 宿主加载的组件 | 宿主版本及 SDK、位数、加载方式和运行入口 | 分开验证组件构建、真实宿主加载及组件声明的行为。 |
| 原型、诊断和示例 | 验证目的、依赖、入口和当前已实现范围 | 用最小输入验证目标，以实际工程入口和产物为准。 |

## 按改动范围选择验证

从本项目契约卡选择实际命令。按改动覆盖所需层级。

| 改动范围 | 验证起点 |
|---|---|
| 文档或接入规则 | 核对入口、引用与命令定义。涉及流程时走查代表性任务。 |
| 业务或数据规则 | 验证关键输入、失败路径及受影响的相邻行为。 |
| UI 或平台行为 | 从受影响的交互入口验证。涉及系统或设备能力时补相应实机检查。 |
| 预览与导出共用的规则 | 用同一输入走预览和导出的实际入口，比较契约要求一致的结果。 |
| 发布或分发 | 验证实际交付物、目标运行时和用户数据保护。 |

## 分层记录验证

- **核心**覆盖规则、序列化和错误边界。
- **集成与交互**覆盖 UI、浏览器、进程或平台 API。注明替身、离屏或真实桌面。
- **真实内容或设备**记录实际提供的词典、文章、音频、浏览器、宿主或设备。缺少素材时标记跳过及影响。
- **交付物**覆盖实际安装或启动入口、依赖提示、数据保护，以及项目承诺的导出或加载行为。历史结果只作追溯。
