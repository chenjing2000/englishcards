# Windows 应用可复用模式

按项目需求选用。每个模式的具体行为和验收由项目契约决定。

## 本地文件安全保存

先确定谁拥有文件及覆盖权限。需要检测外部修改时记录读取版本，并在提交前按项目契约重新校验。先校验待保存内容，再在目标目录写入本次拥有的临时文件。依据文件系统能力和项目契约替换或移动到目标，已有文件按约定保留备份。提交成功后才更新持久状态标记。失败时保留应保留的源文件，清理本次拥有的临时文件或提供恢复位置。

验收覆盖首次保存、覆盖保存、旧版或损坏输入、外部修改、拒写和重试。若支持并发写入，验证提交时的冲突判定与结果归属。

## 单实例与托盘

首个实例拥有窗口、托盘及后台服务。后续实例转交唤醒请求，明确启动尚未完成及已有模态窗口时激活谁。契约分别定义手动启动、系统登录启动、关闭、最小化、隐藏与真正退出。退出前按项目约定处理未保存状态和任务，再释放定时器、事件订阅和托盘资源。

验收覆盖重复启动、模态激活、隐藏后的后台行为、退出取消及真实退出。声明支持开机启动或跨屏时，加验真实登录和多屏 DPI。

## 长任务取消与产物提交

任务开始时固定输入快照与目标路径，隔离各任务临时文件。区分运行、取消清理、校验、提交和终止状态。明确提交边界，在可以安全取消的阶段停止任务并回收资源。已进入提交时根据契约完成提交或恢复，确保最终文件状态可解释。校验临时产物后才提交正式输出，提交失败时保护既有结果并明确可恢复产物的位置。

验收覆盖运行中取消、提交边界、退出等待、失败重试、既有产物保护，以及用真实产物确认内容和时序。

## 便携程序的暂存发布

若项目以单 EXE 交付，先发布到隔离目录，检查产物形态和入口，再更新正式路径。发布脚本只替换它负责的应用文件，保护设置、备份和用户目录。开发构建、发布和启动分别写明入口。仓库已有发布脚本或 profile 时从该入口执行。

若项目承诺可移动，复制交付物到含空格的隔离目录，从另一工作目录启动，检查资源与设置路径。缺少运行时的验证应使用隔离环境。只有项目明确承诺支持改名时才将改名纳入验收。

## 外部素材与异步会话

区分用户选择的源文件、派生资源、索引和缓存。把查找范围、匹配优先级、同名冲突和解码失败后的处理写进契约。切换文档、词条或音频时，旧会话的异步结果不得覆盖当前选择，停止或关闭时释放本次拥有的资源。

使用固定小样本覆盖正常和错误路径。真实词典、文章、教材和设备单独验证，样本通过只代表相应格式与用例的证据。
