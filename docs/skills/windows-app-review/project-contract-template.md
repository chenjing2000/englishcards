# 项目契约卡模板

卡片记录现行约定和实际入口。详细规格使用相对链接，保留足够的摘要，以便共用目录不可用时继续工作。按项目规模填写。

## 如何运行与交付

- 用户入口、运行形态、开发 SDK、目标框架、系统架构及运行时依赖。
- 从仓库根目录执行的构建、启动与发布命令，以及实际产物。按需写明浏览器地址或宿主加载方式。

## 哪些行为必须保护

- 主流程、关键交互、状态所有权和生命周期。列出适用的项目规格及专属检查。
- 适用的通用模式、项目自己的选择或例外。

## 数据在哪里

- 用户数据、设置、缓存、外部素材和输出的位置及归属。外部样本通过明确参数传入。
- 支持的格式及版本，旧版、失败、重试和覆盖规则。涉及迁移时链接保护与恢复方案。

## 如何验证

- 常用命令、定向检查入口及所需样本。记录缺少样本时的覆盖范围。
- 按 [验证分层](runtime-profiles.md#分层记录验证) 标出需要真实 Windows 会话、浏览器、设备、宿主或交付物的检查。
