# EnglishCards 只读 Script 阅读器改造实施方案

> **状态：待实施、仅设计文档。** 2026-11-22 讨论确认；本文未代表代码已经实现或通过验收。
>
> **代码基线**：EnglishCards `main` 仍为 Article v6 编辑器。本计划与 [PR #11](https://github.com/chenjing2000/englishcards/pull/11) 中 `docs/handoff.md` 第 7 节已同步 2026-11-22 最新决定，包含按钮、目录树、Script 切换时的媒体／浮窗生命周期、默认时长页间锚点与零时长页面规则。两份文档均为**待实施设计**，并非已完成的程序功能。
>
> **实施权限边界**：本次只记录计划，不修改生产代码、不创建实施 PR、不合并 `main`；各阶段须经用户明确批准后才能动工。不得覆盖本机未提交修改，尤其 `clover_icon.ico`。性能测试及无关测试继续暂停。

## 1. 目标、原则与非目标

目标是将 Windows 端 EnglishCards 从 Article v6 **编辑器**改为使用 Script JSON 的**单页只读阅读器**，同时保留按需新增生词、文章独立设置、PNG 静态图片及 MP4 视频导出。

- **第一性原理 / 奥卡姆剃刀**：优先删除失去用途的编辑器链路、联合保存、ZIP 导出及旧数据适配，不叠加兼容层；只在实际复用价值明确时抽象。
- **参考而不盲目搬运**：ReadArticles 提供目录树、设置图标、播放器、选词及浮窗的交互参考；ScriptToVideo 提供媒体探测、Remotion MP4 渲染、进度／取消、临时文件及安全提交的实现参考；EnglishCards 自身已稳定的分页、独立 WebView2 捕获、文件写入保护应优先复用。
- **数据边界**：Script 和 Translation 只读；用户添加生词是 Vocabulary 的唯一受控内容写入。设置写入 `settings.json`，导出写入独立目录。
- **不新增**：清空按钮、目录刷新按钮、目录监视器、后台递归扫描、旧 Article v6 兼容／迁移、ZIP 导出、独立 JSON 保存按钮、Passage/Script 模式切换，以及无明确用途的读者操作按钮。
- 本文关注**实施顺序、责任模块、交互契约、风险和验收口径**；不在设计阶段预先创建大量代码接口或文件。

## 2. 最终界面和按钮契约

### 2.1 左侧卡片馆

布局自上而下：

1. **顶部一行**：「选择卡片馆」文字按钮；其右侧紧邻一个**图标设置按钮**。图标使用 ReadArticles 的 `ReadArticles/ui/icons/setting.svg`，采用其 32×32 圆形交互区域及悬停／按下样式，Tooltip 为「设置」。
2. **中部目录树容器**：占据可伸缩空间，仅显示选定卡片馆根文件夹**内部的子目录和 Script JSON**，不显示根文件夹本身为树节点。
3. **底部固定操作区**：只保留 **PNG、MP4** 两个按钮，左对齐。PNG 的 Tooltip **精确为「保存」**，实际功能仍是保存全部 PNG 静态分页；MP4 的 Tooltip 为「导出 MP4」。

不再出现「清空」或「刷新」按钮。PNG 不是 JSON 保存、更不是 ZIP 联合保存。无可导出 Script、正在发生互斥导出或出现其他不满足前置条件的状态时，应根据功能禁用对应操作，避免无效请求。

### 2.2 右侧阅读区

- 删除原右侧 Vocabulary／Content／Translation 编辑栏、编辑分割条和相关编辑按钮，保留一张阅读卡片的预览区域。
- **翻页**：上一页、下一页按钮及页码显示；到首页／末页时相应按钮不可用。
- **播放**：播放／暂停使用同一个切换按钮；另有停止按钮和可拖动媒体进度条。借鉴 ReadArticles 的快捷键、播放状态和通知，不添加冗余播放入口。
- **选词**：只有在有效 Script 句内选中词／短语时，才显示 ReadArticles 风格的蓝色圆形「+」；这是按需出现的按钮。
- 主界面功能按钮共 **9 个**：顶部 2、目录树底部 2、阅读区 5（上一页、下一页、播放／暂停、停止、选词加号）。进度滑块和页码不是额外功能按钮。设置弹窗及导出过程中的按钮不计入主界面数量。
- **设置弹窗**：按 ReadArticles 分组风格，保留「恢复默认」「取消」「保存」。仅对当前 Script 的设置生效；全局卡片馆位置等信息仍由程序级设置持久化。
- **任务／确认弹窗**：MP4 导出时提供取消操作；覆盖、安全提交或错误时按需出现确认／通知，避免在主界面常驻临时按钮。

### 2.3 目录树加载、刷新与预览保持

以用户选择 `D:\EnglishLibrary` 为例：

```text
D:\EnglishLibrary\       （卡片馆根目录，不是树节点）
├── The Economist/        （显示的首层节点）
│   ├── A.json            （仅 filetype=script 的文件显示）
│   └── B.json
├── Speeches/
└── C.json
```

- 卡片馆根目录本身不是节点；选择卡片馆后枚举其**直属**子目录和 Script 文件作为树顶层。**不引入 ReadArticles 的 book.json 标记约束**，只借鉴其根目录表现和逐层 Lazy Tree 行为。
- 子目录通过现有 `+`／`−`（展开／折叠）符号操作：展开仅扫描**该层**直属子目录与 JSON、通过顶层 `filetype === "script"` 识别文件；折叠释放当前节点的子级缓存，下一次展开重新枚举该层。不能只凭文件名后缀识别类型；不递归预扫描，不预先查找媒体。
- 隐藏程序产物目录 `cache/`、`export/` 及不应显示的应用内部目录；不能误隐藏正常的用户 Script 目录。统一稳定排序。
- **当前已经有 Script 打开时**：任意目录的折叠、展开、重新枚举都**只更新树**；不主动重新加载、切换、清空、重新分页或停止当前 Script／媒体。即使展开目录中只有另外一个 Script，也不能抢占当前阅读。
- **当前没有 Script 打开时**：对当前加载到的目录，只有 1 个 Script 时自动打开；有 2 个或更多时不任选第一个，等待用户点击具体文件；没有 Script 时保持空白阅读区。根目录直属 Script 亦依此规则处理。
- **用户明确点击某个 Script 文件**：才切换到该文件；同目录出现多个 Script 时点击哪个就打开哪个。无须另增“点击目录名称选择目录”的独立交互。
- **根目录刷新**：因为根目录不是折叠节点，通过再次执行「选择卡片馆」（即使选回同一路径）重新枚举根目录直属内容；不新增刷新按钮。选择同一路径仅刷新目录树，**不重载已打开的 Script 或媒体，不清空当前消息**；切换为不同卡片馆时安全结束旧 Script／媒体会话并清空旧消息；取消选择或新目录读取失败时维持原会话。
- 文件外部更改或删除后，目录项刷新不能破坏已有预览的生命周期；若用户之后明确打开失效文件，按正常错误提示处理，不悄悄选择别的 Script。目录展开／折叠行为参考 ReadArticles 的逐层读取、取消过期扫描、结果代次保护和读取失败提示，但优先沿用 EnglishCards 已有实现，不引入 ReadArticles 的 `book.json` 约束。

## 3. Script / Vocabulary / Translation 契约

### 3.1 Script 是唯一必需输入

- 仅接受顶层 `filetype: "script"` 的 JSON；以 ScriptTimestamp / `script-timestamp-aligner` Skill 的 Script 数据为正式结构：`title` 必需但可为空串，`paragraphs` 为段落数组，每句有 `text` 和 `timed_units`。
- 原文**严格由句子的 `text` 字段显示**，绝不靠拼接 `timed_units` 恢复正文。标题为空不显示，不能借用文件名兜底。
- 时间戳 `null` 或无效时间信息的单元照常显示文字，不参与随播放时间变化的高亮；其他有效时间戳正常高亮。

### 3.2 Vocabulary、Translation 可选

- 仅按顶层 `filetype` 识别，允许同目录多个同类型文件。
- Vocabulary 直接使用 ReadArticles Vocabulary Enrichment Skill 的结构，包括 `words`、`word`、`family`、英／美音标和 `meanings`；不转换为旧 Article v6。
- Translation 仅为 `{"filetype":"translation","text":"..."}`，`text` 是保留换行的纯文本；缺失时正常阅读。
- 某类型存在多个文件时，按**确定性的文件名顺序**选用第一个，并用普通浮窗告知选中哪个；其余文件不删除、不覆盖。
- 有 Vocabulary 时，选词新增必须写入**当前实际打开的 Vocabulary JSON**；没有 Vocabulary 时，**首次**新增生词创建 `<script>.vocabulary.json`（例如 `lesson.script.json` → `lesson.script.vocabulary.json`），并把它作为当前活动生词本。
- 仅在有效 Script 句内允许选词／短语，复用 ReadArticles 的选区校验、重复项判断和原文位置映射；成功新增时立即执行**原子写入及外部修改冲突保护**，磁盘保存确认后才提示成功。导出不补写 Vocabulary。
- Script、Translation 与原媒体绝不因为阅读、加词或导出被修改。

## 4. 阅读、媒体与独立设置

### 4.1 单页分页、Script 媒体会话与播放

- 预览始终仅显示 **1 张卡片**，分页内容按 Script → Vocabulary（可选）→ Translation（可选）组织；可翻页，页码与实际分页一致。
- **加载或切换到一个不同 Script 时，立即开始媒体候选搜索并逐一尝试打开／解码**，不等用户点击播放。只检查该 Script 所在目录的**直接文件**，按 `.mp4 → .mkv → .m4a → .mp3 → .wav`，同后缀依文件名升序尝试；第一个**确实可以解码**的媒体即成为当前会话唯一媒体，停止后续检索。文件存在、扩展名匹配或只读到元数据均不代表已解码成功。不按 Script 文件名同 stem 限制，不递归、不拼接。
- 搜索和解码应随 Script 打开**启动**，但使用非阻塞 UI 的异步工作方式；文字可先显示。媒体未确定期间布局及 MP4 时长不能视作最终状态；确定视频／音频／无媒体结果后，按实际媒体区域完成或更新分页，并验证时长设置。成功加载媒体后**保持未播放状态**，用户点击播放才开始播放。所有候选均失败或不存在时不加载媒体，仍能阅读、翻页、加词及导出 PNG。
- 已确定媒体与**当前 Script 阅读会话绑定**：播放和导出均使用这一已选定的媒体文件，导出时可以验证它是否仍可访问／被导出工具支持，但**不能重新挑选另一个媒体候选**。若导出工具不支持当前已选定文件，提示失败，不静默切换素材。媒体播放过程中失败时也不自动切换媒体。
- 只有**真正切换 Script** 时才终止旧媒体加载／播放，释放旧资源，重新查找并加载新 Script 媒体。目录折叠、展开、刷新和同路径卡片馆重新选择不引发媒体重新加载；重复点击当前同一 Script 不主动重载。切到不同卡片馆则安全结束旧阅读会话。
- 每次成功进入不同 Script 会话时，清除**全部旧普通／警告／错误消息浮窗**及相关选区／高亮临时状态；新 Script 可以重新发出自己的消息。旧会话迟到的异步结果、媒体回调和通知必须因会话标识不再有效而被忽略。对于未完成的 Vocabulary 写入或导出任务，按既有安全完成／取消规则处理，不能把关闭通知误认为操作已取消。
- 选中视频时：播放器固定在阅读卡片顶部，**翻页不能重建／重载播放器**，正文使用扣除视频区域后的空间。选中音频时：从同目录按 `.png → .jpg → .jpeg`、同后缀文件名排序取第一个有效图片，**仅第一页**显示；无图片则不显示图片区。
- 将 Vocabulary 静态词汇高亮与有效 Script 时间戳驱动的动态播放高亮独立处理。播放／暂停、停止、进度条、快捷键和消息浮窗参考 ReadArticles；不增加重复控制。

### 4.2 每 Script 独立设置

- 文章级页面样式、播放与视频导出配置位于 `<Script 所在目录>/export/<script>/settings.json`，其中 `<script>` 表示去掉**最后一个** `.json` 后的 Script 文件名；例如 `lesson.script.json` → `export/lesson.script/settings.json`。
- 同目录同文件名重开可沿用旧设置；**重命名 Script 即新配置身份**，不搬迁旧设置；不同目录同文件名互不干扰。
- 加载文章时先读取并应用有效设置，再结合 Script 与**已确定的媒体类型／布局**计算最终分页；媒体异步加载期间允许先显示文字，但最终页数与时长应在媒体结果就绪后重新核对。无设置文件时采用默认值，**不要仅因打开阅读而强制写盘**。目录不可写不得阻止只读阅读；实际保存失败须明确提示，不伪称保存成功。
- 视频设置下方的**四列表格**：`页码 | 停留时间 (s) | 页码 | 停留时间 (s)`；左列按 `1 … ceil(N/2)`，右列接续到 N；奇数页右下留空。页码不可编辑；**N 指 MP4 视频布局的总页数**，不能混入 PNG 独立重分页的页码。
- 严格使用 `DefaultDurationMs`（程序建议）及 `ModifiedDurationMs`（用户值），首次两者相同。**不累加页面各词的朗读时长**。设当前页末尾向前查找的**最后一个有效时间戳单词的结束时间**为 `T_i`，前置锚点 `T_prev` 为此前最近一个含有效时间戳页面的最后有效结束时间（首次为 `0 ms`），则 `DefaultDurationMs_i = T_i - T_prev`；因此包括单词间的停顿。若本页末尾若干单词的时间戳为 `null`，仍取本页最后一个有效单词；**整页没有有效时间戳则 `DefaultDurationMs = 0`，且不更新前置锚点**，供后续页面计算。Vocabulary／Translation 独立页不另加时长；先将锚点统一为整数毫秒再求差，非递增／异常时间戳应校验提示，不产生负默认时长。
- 输入仅接受 ASCII 数字与最多一个小数点、最多三位小数（界面秒，内部整数毫秒）。输入过程中可暂时为空或以小数点结尾；仅在 **Enter 或失焦**时提交。为空或小于该页默认值时恢复为默认值、刷新表格并显示普通消息；已保存旧值低于新默认值时同样钳位、提示。默认 3132 ms 显示 `3.132`，默认 0 ms 显示 `0.0`。
- **始终要求 `ModifiedDurationMs ≥ DefaultDurationMs`**：因此仅默认 0 ms 的页面允许用户设为 `ModifiedDurationMs = 0`，但不因是否存在 `null` 文字或原媒体朗读而添加其他跳页限制。保存／导出不得含非法数值。正文、样式、媒体或分页变化后须重新计算默认值并校验用户值，**不得将旧页号无条件对应到新分页**；分页边界无法可靠对应时重置受影响的修改值并提示，不设计复杂历史迁移。

## 5. 文件输出、PNG 与 MP4

### 5.1 路径与提交保护

- 每个 Script 独立使用同目录的 `cache/<script>/` 及 `export/<script>/`；缓存仅按任务需要创建 `render/`、`media/`、`temp/` 等子目录，不创建空目录。
- 配置是持久数据，不能放在可清理缓存中；原 Script、Vocabulary（除明确加词）、Translation、音频与视频保持不变。
- 任何导出先生成任务专属的临时结果并验证，成功后才安全发布到正式位置；失败／取消保留既有正式结果并清理本次临时文件。不能将导出 MP4 放到 Script 根目录，否则会被下一次媒体查找误选。

### 5.2 PNG：Tooltip「保存」

- 直接导出当前 Script **全部**静态卡片到 `export/<script>/images/page-001.png` 等，不生成 ZIP，不把旧 JSON＋ZIP 联合保存重新引入。
- 保留 EnglishCards 已有的独立 WebView2 逐页捕获、尺寸及 PNG 验证机制，避免捕获正在阅读的可见 WebView2。
- 使用当前 Script 会话**已选定**的媒体而不为导出重新找另一个候选。如当前是视频，提取**第一帧**放在 PNG **第一页顶部**，后续页不再放视频区域，并按静态页面**重新分页**；提帧不能中断正在播放的视频。如为音频配图，也只放在 PNG 第 1 页。无媒体时仍可导出纯文字 PNG。
- 先生成完整临时图片批次，校验所有页，再整体、安全替换正式 `images/`，不能把两次导出的新旧不同页数混在一起。
- **阅读版／MP4 版分页与 PNG 版分页可以不同**；不能复用 PNG 页号作为视频逐页时长表的主键。

### 5.3 MP4：视频时间轴

- MP4 使用**Script 加载时已经确定的媒体源**；导出时仅再验证该文件与导出器可用性，不得擅自换成另一候选。参考 ScriptToVideo 的 Remotion 渲染、媒体探测、编码进度／取消、子进程生命周期和输出验证／防覆盖；不引入其 v3 编辑数据结构、同名媒体限制或 revised/TXT/project 保存链。
- **只看最终 `ModifiedDurationMs` 决定是否跳页**：凡 `ModifiedDurationMs = 0` 的页面都**无条件跳过 MP4 画面渲染**，无论页面有无文字、`null` 时间戳或对应原始音频；阅读及 PNG 仍保留。不得因音频情况自动把零时长页改成正时长，也不增加额外跳过条件。正时长页照常渲染；如全部为 0，则提示无可渲染画面，不创建无效 MP4。
- 为延长停留时间，需建立**原媒体时间轴 → 导出时间轴**的明确映射，研究画面冻结／静音等必要策略，不直接修改 Script 原时间戳、不擅自变速或裁掉朗读。**`ModifiedDurationMs ≥ DefaultDurationMs` 是确定的输入限制，不等同于已证明全部原始音频能与视频总时长匹配**；零时长跳页规则保持不变，针对原始音频尾段、缺失时间戳及总时长不足的映射方案留待 C2 专项确认，**目前不新增“总时长不足禁止导出”之类未经批准的规则**。
- **实施阻塞点（专项设计，非新增功能）**：默认时长的相邻有效**页末朗读结束锚点之差**已经确定，但编码前仍需明确用户增加的停留时间如何插入、零时长页无画面的原始媒体片段如何映射、无时间戳片段和媒体尾段如何处理，使用代表性样例验证；未确认前不得宣称 MP4 导出时间轴已完成。
- 仅点击 MP4 导出时检查相应依赖；缺少 MP4 环境不能阻止阅读、加词或 PNG 导出。

## 6. 分阶段实施顺序与验收门槛

> 以下是未来**审批后的工作分解**，不是本次要执行的命令或已完成状态。每阶段先对照当时最新的 EnglishCards、ReadArticles、ScriptToVideo 实际源码检查，再以最小可验证修改实施；阶段验收后才讨论下一阶段。每阶段代码分支／PR 的创建均需用户授权，未经确认绝不合并。

### 阶段 A：数据、目录树、阅读 UI 与 Vocabulary

**A1. 移除旧编辑主路径，建立只读数据入口**

- 以 Script 为唯一打开对象；解析和显示 Script 的 `title`、`paragraphs[].text`，容忍 null 时间戳；识别可选 Vocabulary／Translation。
- 把双栏编辑器改为左侧卡片馆＋右侧单页预览，移除失去用途的编辑与联合保存入口；不额外保留 Article v6 兼容层。
- 左侧顶部「选择卡片馆＋设置图标」，底部「PNG＋MP4」（PNG Tooltip「保存」）；阅读区翻页、页码及选词加号按新契约；**PNG／MP4 按钮在该阶段可暂时不可用，不能伪装已实现**。

**A2. 目录树及状态生命周期**

- **复用既有 `CardLibrary.tsx` 的根目录隐藏、Lazy Loading、折叠重新展开刷新，以及 `libraryRevision` 同路径刷新机制**；针对 `filetype` 过滤、产物目录隐藏和请求取消／结果代次保护做最小修改，参考 ReadArticles 的动作行为，不复制整套目录树。
- 单 Script 自动加载仅在**尚无已打开 Script**时发生；多 Script 等用户点击；已有 Script 在任何展开／折叠操作下维持预览不变。
- 明确区分“目录刷新”和“用户主动切换文章”：同路径根刷新只更新树，换卡片馆则安全关闭旧 Script；真正切换 Script 时清除旧消息浮窗（阶段 B 同时实现旧媒体释放与新媒体自动加载），防止刷新意外重新分页／清除阅读状态。

**A3. 生词本与设置最小闭环**

- 当前活动 Vocabulary 选择、多文件普通通知、选词规范校验、无 Vocabulary 时首次创建及受控原子保存／冲突保护。
- 实现每 Script `settings.json` 的**基础样式设置**读取、编辑与保存，先应用样式再分页；无文件用默认值、只读打开不强制写盘，恢复默认／取消／保存语义明确。依赖最终视频分页的四列时长表与时间计算留到 C2，避免在阶段 A 反复返工。

**A 阶段验收**：根目录不显示、子目录刷新、已打开 Script 保持、0／1／多个 Script 选择规则、空标题、null 时间戳、可选文件／重复类型、生词即时落盘及冲突保护、单页翻页、设置身份与只读目录降级。

### 阶段 B：媒体播放、通知与高亮

- **在每次加载不同 Script 时立即启动媒体检索、按格式和文件名逐个尝试解码并选定首个可解码源**，不等待播放按钮；全部失败则无媒体，不自动播放。播放和 PNG／MP4 使用同一个已选定文件，目录刷新不重新加载；异步结果以 Script 会话标识判定是否过期。
- 复用 ReadArticles 风格的播放／暂停、停止、进度、快捷键、普通／警告／错误浮窗；**切换 Script 时清除全部旧消息浮窗**，迟到的旧会话通知不可重现，切换后新消息正常显示。
- 视频顶部固定，翻页不断流；音频选图仅第一页；有效时间戳高亮，null 不高亮；Vocabulary 静态高亮独立。
- **B 阶段验收**：加载 Script 时立即选定并尝试解码媒体、后缀优先级／解码回退、成功后不自动播放、切换 Script 重选媒体且清空所有旧消息、无迟到媒体回调／浮窗、中途播放失败、拖动定位、翻页不重载视频、配图仅首页、无媒体可读文，以及刷新目录树不影响播放或预览。

### 阶段 C：静态 PNG 与 MP4 导出

**C1. PNG 与隔离路径**：实现完整静态重分页、视频首帧／音频首图仅首页、独立捕获、`images/` 批次安全替换、缓存与最终产物按 Script 隔离。

**C2. MP4 设置与导出**：先落实“当前页最后有效单词结束时间 − 此前最近有效页的结束时间”及空页 0 ms 的计算，再专项确定媒体时间映射；随后实现四列时长表、Enter／失焦校正、`ModifiedDurationMs ≥ DefaultDurationMs`、零时长页无条件跳过、全部零时长拒绝、Remotion 进度／取消、媒体及输出验证、安全提交。不得在算法未定时擅自增加新的视频导出限制。

**C 阶段验收**：PNG 全页及二次导出没有旧图片残留、视频首帧且播放不中断、PNG／MP4 页数独立、设置持久化和重命名规则、最多三位小数及普通提示、含停顿的页间锚点差／页末 `null`／整页 `null`／连续无锚点页、零时长页无条件跳过与全零拒绝、导出沿用当前会话媒体、MP4 时间轴映射／音画同步、取消及异常不破坏旧输出。

## 8. 风险、边界情况与验证策略

1. **目录树刷新与异步竞争**：展开后异步返回、折叠后再展开、连续切换 Script 时，旧请求不得覆盖新树或当前预览；树与阅读状态独立。
2. **根目录不是节点**：和 ReadArticles 的表现一致，但不能照搬其 `book.json` 过滤方式；确保直属 Script 文件实际可见。
3. **生词即时保存**：已有 Vocabulary 的活动文件身份、并发修改／外部覆盖、首次创建冲突及写入失败须明确反馈；原文和媒体严格只读。
4. **媒体支持差异**：Script 加载即逐个尝试解码，文件存在不等于可解码；媒体候选与导出应绑定同一已选定文件，切换 Script 必须重新加载，刷新目录则不重新加载；视频翻页不得重新初始化媒体。
5. **分页和时长失配**：样式、字体、视频占位和正文修改都可能改变页面边界；不盲目按旧页号复用 `ModifiedDurationMs`；按最近有效页末结束锚点求差，整页无时间戳不推进锚点，校验时间戳单调性；PNG 版与 MP4 版分开计算。
6. **导出可恢复性**：图片目录替换、MP4 防覆盖、跨磁盘临时文件及取消时的完整清理不得破坏上次成功结果。
7. **音画同步**：零时长页面无条件不渲染、页面时长下限为已定约束；但它不能单独保证原音频时长完全匹配。延长停留时间、缺失时间戳与音频尾段的映射算法仍须专项确认；不擅自补时、改变跳页判定或新增“总时长不足禁止导出”的业务规则。
8. **文档与真实代码状态**：当前 `main` 的 `AGENTS.md`、正式产品契约、专项规格仍服务 Article v6；未来批准代码改动时才按阶段同步。不能把旧 CI 结果当作新方案验证。

**验收策略**：每阶段先做与该阶段范围直接相关的必要功能验证，必要时由用户在 Windows 实机验收；**性能基准、无关测试和无目标重构仍暂停**。每次验收说明应明确“代码实现了什么／未实现什么／自动化结果与实机结果分别是什么”。未经用户确认，不合并实施 PR。
